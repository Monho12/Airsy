# AERIS: ухаалаг барилгын бодит цагийн Digital Twin

AERIS бол олон давхар барилгын агааржуулалт ба дотоод агаарын чанарыг (IAQ) хянах, бодит цагийн интерактив вэб апп.
Барилгыг 3D digital twin хэлбэрээр харуулна. Давхар бүрийн мэдрэгчийн утга шууд шинэчлэгдэж, дүрэмд суурилсан
удирдлага сэнс ба гадна агаарын хаалтыг автоматаар тохируулна. Систем шийдвэр бүрээ «Яагаад?» гэсэн тайлбартай
гаргана.

> ⚠️ **Энэ бол симуляци.** Бүх утга браузер дотор үүснэ. Жинхэнэ мэдрэгч, төхөөрөмж, backend байхгүй.
> AERIS нь баталгаажсан барилгын удирдлагын систем биш, гал болон амь насны аюулгүй байдлын систем ч биш.

Репозиторийн нэр `Airsy`, бүтээгдэхүүний нэр **AERIS**. Advanced Web Development хичээлийн төсөл. UI бүхэлдээ
Монгол хэлээр.

## Юу харуулдаг вэ

- **3D барилга** (Three.js + React Three Fiber). Барилгыг эргүүлж, ойртуулж болно. Давхар, өрөө, мэдрэгчийг
  сонгоно. Cutaway нүүр, агаарын урсгалын шугам, өрөө, лифт, эвакуацийн шат харагдана.
- **Шууд мэдрэгчийн өгөгдөл.** 12 давхар, 90 бүс, 450 дотоод + 3 гадна мэдрэгч хэмжинэ: температур, CO₂, чийгшил,
  PM2.5, VOC индекс. Ижил seed-ээс эхэлбэл ажиллуулалт бүр яг ижил давтагдана.
- **Ангилал.** Утга бүр хэвийн / анхааруулга / ноцтой / холболтгүй / буруу утга гэж ангилагдана. Босго hysteresis-тэй.
  Холболтгүй мэдрэгчийг хэзээ ч 0 гэж үзэхгүй.
- **Автомат удирдлага.** Дүрэм тус бүр тэргүүлэх эрэмбэтэй. Debounce, барих хугацаа, гадна агаарын хязгаарлалт
  хэлбэлзлээс сэргийлнэ. Төхөөрөмж бүрийг гараар удирдаж, дараа нь автомат руу буцааж болно.
- **Дохио ба үйл явдлын түүх.** Дохиог шүүж, хүлээн авсан гэж тэмдэглэнэ. Системийн шийдвэр бүрийн тайлбар
  түүхэнд үлдэнэ.
- **8 үзүүлэх сценари ба 5 өрөөний сценари.** Сценари эхлэхэд тухайн давхар автоматаар сонгогдоно.
- **Бүх дэлгэцэд тохирно.** Desktop, таблет ба утсанд ажиллана (утсан дээр 4 табтай). Гараар бүрэн удирдана,
  дэлгэц уншигчид ноцтой дохиог мэдэгдэнэ, хөдөлгөөн багасгах тохиргоог дагана.

## Ажиллуулах

Шаардлага: **Node.js ≥ 24** (шалгасан: 24.13.0) ба npm 11.

```bash
npm ci          # dependency-г lock файлаар суулгана
npm run dev     # хөгжүүлэлтийн сервер → http://localhost:5173
```

| Скрипт                 | Үүрэг                                           |
| ---------------------- | ----------------------------------------------- |
| `npm run dev`          | Vite dev server                                 |
| `npm run build`        | Төрөл шалгаад production багц бүтээнэ (`dist/`) |
| `npm run preview`      | Бүтээсэн багцыг локалаар үзүүлнэ                |
| `npm run typecheck`    | TypeScript (strict) шалгалт                     |
| `npm run lint`         | ESLint, түүн дотор модулийн хилийн дүрэм        |
| `npm run format:check` | Prettier шалгалт                                |
| `npm run test:run`     | Бүх тест нэг удаа (Vitest: domain, UI, tooling) |

Хамгийн сайн нь WebGL2-той Chrome эсвэл Edge-ийн сүүлийн хувилбар. WebGL байхгүй бол 3D-ийн оронд 2D давхрын
жагсаалт харагдана.

## Архитектур

```
UI (React)           app/ · features/* · components/ui
   ▲ selector-оор уншина           │ runtime.dispatch(command)
Төлөв (Zustand)      store/: liveStore (snapshot), uiStore (сонголт, шүүлт)
   ▲ subscribe(snapshot)
Runtime хил          domain/runtime: AerisRuntime ← LocalSimulationRuntime (одоо) / RemoteRuntime (ирээдүй)
   ▲
Domain (цэвэр TS)    types · config · classification · simulation · control · alerts · events · scenarios · i18n
```

- **Domain давхарга** нь React, DOM, `Date.now()`, `Math.random()` хэрэглэдэггүй цэвэр TypeScript. Тиймээс
  удирдлагын дүрмийг браузергүйгээр тестлэж болно. Ирээдүйд энэ давхарга сервер дээр өөрчлөлтгүй ажиллах боломжтой.
- **UI симуляцитай шууд харьцахгүй.** UI зөвхөн `AerisRuntime` interface-ээр командаа илгээж, snapshot хүлээн
  авна. Ирээдүйд WebSocket backend нэмэхэд UI дахин бичигдэхгүй.
- Давхаргын хилийг ESLint (`eslint-plugin-boundaries`) сахиулна, зөрчлийг тусгай тест шалгана.

Шаардлага, дизайны систем, бүх шийдвэрийн бүртгэл [CLAUDE.md](./CLAUDE.md)-д бий. Энэ нь төслийн цорын ганц эх
сурвалж.

## Үзүүлэх скрипт (~8 минут)

1. **S1 Хэвийн ажиллагаа.** Барилгыг эргүүлж, 12 ба 2-р давхрыг сонгоно.
2. **S3 Өндөр CO₂** (2× хурдаар). 2-р давхрын агаар оруулах сэнсний «Яагаад?»-ыг нээнэ.
3. **S5 Гадна агаар муу.** Удирдлага «илүү цэвэр агаар» ба «гадна агаар бохир» гэсэн хоёр шаардлагын хооронд
   хэрхэн шийдвэр гаргаж байгааг харуулна.
4. **S7 Мэдрэгч салсан.** «Өгөгдөлгүй» нь 0 биш гэдэг ба нөөц горимыг харуулна.
5. **S6 Яаралтай байдал.** Доорх анхааруулгыг чангаар уншаад, яаралтай байдлыг дуусгана.
6. **S8 Сэргэлт** (5× хурдаар). Дохио шийдэгдэж буйг ба үйл явдлын түүхийг харуулна.

«Симуляцийг эхнээс нь» товч бүгдийг эхлэх төлөвт буцаана.

## Яаралтай байдлын анхааруулга

> Энэ бол сургалтын симуляци. Батлагдсан гал, утааны хамгаалалтын систем биш. Жинхэнэ гал мэдээллийн дохиолол,
> нүүлгэн шилжүүлэх журам, аврах албыг орлохгүй.

Босгын утгууд нь дотоод агаарын чанарын нийтлэг зөвлөмжөөс сэдэвлэсэн **прототипийн үзүүлэх утга**. Тэдгээр нь
хууль эрх зүйн эсвэл стандартын утга биш. Симуляцийн загвар нь дүрслэх зориулалттай, физикийн хувьд нарийн биш.
